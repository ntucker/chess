# Approved plans

A plan in this folder is approved: Nathaniel approves a plan by merging it here. Each piece of work a
plan breaks down into has a heading such as `### Piece K: Lesson screen thin slice`. Piece ids are
letters, digits and dashes.

A PR that builds a piece says so in a `Plan piece: <plan>/<piece>` line (`<plan>` is a file name here
without `.md`), and explains any difference from the plan in a `Plan deviations:` line. The piece is
its approval to autoland (`.agents/projects/autoland.md`).
